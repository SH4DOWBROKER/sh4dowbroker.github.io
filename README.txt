ADITHYAN — 3D PORTFOLIO VARIANT 02

This is a substantially different visual direction from the first portfolio:
- futuristic black / acid-green system interface
- large typographic hero
- interactive 3D machine built with Three.js
- radar/target HUD
- modular skill cards
- project stack
- certificate verification list
- social network grid
- contact transmission panel
- animated boot sequence
- mouse parallax and 3D tilt

index.html

The contact form is frontend-only until connected to a backend/email service.
